# ADR 0007：M6 观看记录、个人列表与显式写命令

日期：2026-10-25。状态：已采用。继续采用 Riverpod + Freezed + MVVM + 整洁架构、iOS 深色玻璃界面和 D-pad 导航。

## 边界

- 本地历史与 B 站历史分别展示。本地进度始终是本设备续播的优先来源，云端较旧的进度不能覆盖它；游客记录不上传、不迁移到新账号。
- 历史列表、收藏夹、收藏夹内容、稍后再看通过独立 LibraryRepository 读取。接口契约参考固定 PiliPlus 提交 `058794483080f5bf3d760e005118c0bd4698c51b`，并在本机实测只读响应后补充记录；不把它声明为 B 站官方稳定 SDK。
- 收藏和稍后再看写入仅由显式用户操作触发，执行时锁定资源，不能放进 Provider build 或失效回调。每次最多提交一次 POST，再强制读取最终状态；超时／网络异常不自动重放，读不到最终状态时显示待确认并只允许重新读取。
- 用户本次授权真实账号只读验收。验收构建以 `MAMBA_READ_ONLY_VALIDATION=true` 阻止个人列表 POST 和进度上报；登录所需的认证协议沿用 M3。合成服务验证写入、超时后确认和账号切换；真实账号写入不作为已通过项。

## 分层与生命周期

Domain 定义历史条目、收藏夹、远端分页、写入确认结果及仓储端口。Data 负责响应映射、CSRF、账号范围检查和最终状态确认；ViewModel 只处理加载、分页、命令状态、取消与代次。View 只处理布局、焦点、确认弹层和路由。

所有远端请求绑定会话 ownerKey／generation。账号切换立即取消旧请求、清除内存私人列表；迟到结果不能写进新账号 UI。私人列表不加入通用 HTTP 缓存或磁盘缓存；当前会话保留的页面数据在刷新失败时明确提示，账号退出后不再可见。写入成功后按资源刷新相关页面，不重放写命令。

Drift v1 升级到 v2，仅新增本地历史封面／标题快照表；原播放进度与搜索记录保留。旧记录缺少快照时显示视频标识，不能因迁移或封面不可用而删除。删除／清空历史只作用于指定 owner 的本地历史及快照，不清除安全凭据、偏好、其他账号或云端历史。

播放器在真实有效进度出现后才形成可见历史。默认倍速／首选 AVC 档位／连续播放从持久设置装配；未提供首选档位时给出说明并使用可用档位。远端观看进度同步默认关闭，用户主动开启后，仅对当前已登录账号的实际播放以至少 30 秒间隔提交；本地保存独立执行，后台与账号切换停止上报，失败不排队重放。

清缓存操作只清理可再生成的 HTTP 内存与封面缓存，保存观看记录、搜索历史、设置和登录凭据。关于页展示实际安装版本与第三方客户端说明；发布依赖清单仍按 M7 交付。

## 验证

覆盖 v1→v2 原数据保留、游客/A/B 隔离、分页去重、刷新失败保留页面、并发写防重、超时后的最终状态确认、待确认时禁止重复写、旧账号响应丢弃、默认设置与缓存清理边界。真实账号仅验证历史／收藏夹／稍后再看读取，截图及响应不公开个人名称、列表标题、Cookie 或账号标识；公开证据使用合成账号或脱敏状态。

验收结果及保留项见 [M6 记录](../m6-validation.md)，v1／v2 schema 快照和生成迁移辅助位于 `test/drift_schemas`、`test/generated_migrations`。
