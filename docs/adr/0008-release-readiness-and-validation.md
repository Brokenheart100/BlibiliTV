# ADR 0008：M7 发布准备与验收边界

日期：2026-10-25。状态：已采用。继续使用 Flutter + Riverpod + Freezed + MVVM／整洁架构。

## 本轮范围

用户将稳定性采样时长由原计划 2 小时调整为 **15 分钟**，M7 本轮据此验收，不将短采样写成两小时通过。保留 20 次进出播放器、自然自动下一 P、有效媒体时间轴、单引擎、原生内存／图片缓存与 UI 帧样本检查。人工音画同步、真实电视、正式密钥与真实账号写入仍分别记录。

主包 `app.mamba.mambatv` 保存用户数据。游客播放测试只安装 `app.mamba.mambatv.validation`，使用独立数据库和内存游客身份，并在 API 层开启只读验证开关。签名升级测试另用新建的专用 AVD，不覆盖主模拟器的主包或安全存储。

## 产品身份与版本

保持现有正式包名与 `1.0.0+1`，不为验收擅自创建标签或公开 Release。版本策略是递增 build number，发布标签严格对应 `v<versionName>`；拆分 APK 按锁定 Flutter 的 ABI 偏移形成实际 versionCode，并在打包时精确校验。正式发布不得重新生成签名身份。

提供自制几何 TV 播放标识：API 24 回退矢量图标、API 26+ adaptive 图标、320×180 xhdpi TV banner，源与生成器一并保留。Android 最低 API 24；三 ABI 能构建不等于三 ABI 均在设备上通过。

## 许可与发布材料

应用内开源许可由按需加载的 Riverpod Provider 提供，合并 Flutter LicenseRegistry 与已收集的原生组件许可，长组件列表和全文支持 D-pad。它不访问账号、媒体或网络，也不在启动时解析全部文本。

包清单从实际解析依赖和 package_config 中的 LICENSE 生成，记录版本、来源与摘要；原生播放器另记录具体二进制来源、构建配方和上游许可，不用 Dart 包装层的 MIT 说明代替 mpv／FFmpeg 的许可。安装说明、设备表、已知限制与变更说明必须和产物一起复核。

临时测试签名只用于验证本机构建与合成数据升级，密钥在构建后删除；不设置仓库 Secrets，不上传标签、APK 或 Release，也不声称正式签名验收完成。
