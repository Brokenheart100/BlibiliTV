# 图标侧栏、浅色模式与首页 Tabs

日期：2026-10-27。

侧栏宽度为 76 逻辑像素，顺序为发现、历史记录、搜索、我的、设置。图标提供 Tooltip／无障碍名称，选中态和遥控器焦点分别保留背景与描边。底部移除账号状态头像，保留太阳／月亮按钮切换深浅色；设置页「外观」还支持跟随系统。偏好沿用 `app.preferences.v1` 的单次 JSON 写入，旧设置缺少主题字段时保持深色，未知主题安全回退；保存失败继续使用已保存的外观。

首页顶部按参考图改为连续胶囊 Tabs，顺序为：个性推荐、正在关注、热门视频、每周必看、排行、直播。浅色使用白色胶囊、浅蓝选中背景和灰色文字；深色使用对应暗色配色。左右键移动焦点、确认切换、向下进入内容，最左侧向左返回侧栏。不同栏目继续隔离列表、分页与焦点记忆。

主题在 MaterialApp 装配，页面颜色通过当前 BuildContext 取得，不使用全局可变颜色。背景、玻璃面板、卡片、按钮、输入框、详情、账号、个人列表、设置与许可页面适配两种亮度。视频画面上的控制层始终使用独立深色主题；封面时长和演示标签保持深底白字。

## 内容边界

后续「我的」五个栏目也复用同一胶囊组件。作者头像与液态玻璃卡片的实现、数据兼容及本轮验证见 [卡片与导航调整](glass-cards-and-navigation.md)。

- 个性推荐、正在关注与热门视频保留原有真实接口；游客进入关注栏目可扫码登录。
- 每周必看通过 `/x/web-interface/popular/series/list` 选最新期，再读取 `/x/web-interface/popular/series/one`；翻页游标固定期号，避免跨周混入另一期。
- 排行通过 `/x/web-interface/ranking/v2` 读取全站排行，`rid=0&type=all`。全量栏目结果按应用页大小分段展示，不能冒充服务端分页。
- 新增请求的路径、WBI 签名与参数核对本机固定参考 PiliPlus 的 `api.dart`／`video.dart`，并通过真实游客响应验证；它们是现有 Web 接口适配，不宣称为 B 站对第三方承诺的稳定公开 API。
- 三个新增内容请求路径纳入账号／会话隔离的 1 分钟内存缓存；主动刷新访问网络。登录和媒体 URL 不进入这份缓存白名单。
- 直播仅保留可到达入口，显示「直播还在准备中」及返回推荐操作，不请求普通视频接口伪装直播，不宣称直播播放已实现。

## 验证

完整 Flutter 回归 **228 项通过**，Flutter MCP 静态分析无诊断，格式检查通过。新增用例覆盖图标语义、六栏顺序和遥控器路径、浅色恢复、跟随系统、旧设置兼容、保存失败保留原设置、播放层主题隔离，以及 640×360／1280×720 的布局与文字可读性。

真实游客接口读取每周必看、排行的首两页，各页 12 条、前后页重叠为 0，远端写入为 0；见 [public-feeds.json](appearance-evidence/public-feeds.json)。可用 `dart run tool/home_feeds_probe.dart` 重验，报告不保存凭据或媒体 URL。

API 36 x86_64 TV 模拟器已安装隔离验证版，原生实测太阳／月亮切换、界面重启后恢复浅色、每周必看和排行展示、设置外观项，以及方向键从侧栏经内容／刷新进入 Tabs 并选择每周必看。Flutter MCP 热重载与热重启成功。自动化检查中曾有驱动等待超时；逐步读取焦点后重验通过，未发现应用自身异常。物理电视与 ARM 本次未验收，未发布或推送。
