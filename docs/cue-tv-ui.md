# Cue 动效与番剧海报

日期：2026-10-29。状态：已实现，278 项自动测试通过。本轮不发布 APK、不改账号写入边界，保留已有 M8／M9 工作区改动。

## 动效

锁定 `cue 0.4.0`，按安装包源码核对 `Cue.onToggle`、`Cue.onMount`、`CueMotion`、`CueValueAnimator` API。采用原有 Flutter／Riverpod／Freezed／MVVM 与整洁架构，Cue 只存在于 UI 层，来源与许可证已纳入依赖清单。

- 按钮和卡片用短促、无明显回弹的弹簧缩放反馈，仍由现有 FocusNode 和方向键逻辑控制，不等动画结束再响应输入。
- 首页和我的主页的 Tabs 使用同一移动胶囊。选中内容与遥控器焦点分别表达；新选择从当前显示位置继续移动，可打断，改变宽度时按栏宽重新定位。
- 番剧标题与确认面板用一次性的 180 ms 淡入／短距离进入。列表卡片挂载不逐个播放入场，不增加循环装饰、动态模糊或着色器。
- 应用“减少动态效果”与系统减少动画共同决定 MediaQuery.disableAnimations。焦点保留边框／颜色，缩放关闭；Tabs 即时定位，控制器释放有测试覆盖。

Cue 用于界面动效，不参与媒体时钟、播放器状态、字幕或弹幕绘制。本轮结果不关闭 M8 持续弹幕性能缺口，也不代表新增动效已通过物理 ARM TV 性能验收。

## 导航

侧栏视觉与上下键顺序统一为：**发现 → 历史记录 → 番剧／影视 → 搜索 → 我的 → 设置**。继续仅显示图标，保留 Tooltip／语义名称及底部主题按钮。

番剧 `/pgc` 成为 StatefulShellRoute 的独立分支，新增内部索引 5，原 0–4 身份保持。删除首页顶部重复入口；进入分支后焦点留在侧栏，向右进入海报，最左列向左回到番剧图标。选集返回、跨栏目返回保留海报 ID／滚动位置。历史记录仍在第二位。

番剧页默认展示标题、打开链接和刷新，链接输入按需展开；成功进入季详情后返回收起输入并聚焦链接按钮，避免小尺寸屏幕被输入框长期占用。链接仍只接受已支持的 B 站 HTTPS 季链接／编号，不新增关键词搜索或短链接解析。

## 海报比例与图片缓存

实际抽查索引中的季 47836、44860、39433，原 PNG 都是 **960×1280，即 3:4**。因此本轮用 3:4 竖版海报，而不是将图片强制改成 9:16。抽样不表示上游所有图片永远同一比例，展示采用 contain 保留不同原图的完整内容。

旧 TvArtwork 同时指定 640×360 的内存解码尺寸；番剧还复用了横版网格，既可能解码变形又会裁掉海报内容。现改为按宽度限制解码／磁盘缩略图，保留图片比例；番剧宽度上限 480，普通视频 640，不再把高固定成 360。新尺寸键不会复用旧 640×360 缩略图，无须清除账号或全局缓存。

番剧网格与我的追番／追剧采用竖版布局；番剧卡片不显示虚构作者头像或缺失观看数。普通 UGC／直播仍保留横向布局及原有作者信息。小尺寸番剧页增加列数，让首张海报和文字可以完整落在视口内。
