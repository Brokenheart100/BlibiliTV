# 详情网格、Tabs 刷新与番剧资料页

日期：2026-10-29。状态：实现完成，本机与 TV 模拟器验证通过。本轮不提交、推送或发布。

## 视频详情的接着发现

保留既有详情信息、播放、选集和收藏／稍后再看入口，将“接着发现”从横向列表改为同一纵向视口中的 SliverGrid。封面、作者头像和卡片玻璃复用现有组件；列表按屏宽排列，卡片懒构建，触摸滚动或遥控器向下都可继续探索。

相关接口 `/x/web-interface/archive/related` 返回有限列表，没有可验证的分页参数。第一批展示相关视频，后续使用现有首页发现推荐流的真实分页；遇到热门回退保留服务端／Repository 提示。当前视频与重复条目过滤；重复游标或连续两页无增量后停止，不拼造无限相关接口。

预加载仅在进入最后两行或滚动接近底部时触发；一次一个分页请求，自动续载保持当前焦点，主动向下跨末行时等待新卡片接续。失败保留旧内容并显示重试，不自动循环失败请求。播放按钮不依赖相关推荐成功。列表与请求按内容／页面／账号代次隔离，后台取消请求；返回相关视频页后恢复卡片位置。

共享网格的自动加载为可选项，本轮只为视频详情启用。支持前置详情内容，焦点定位计算包含头部高度，避免在海报／简介区域错误寻找网格卡片。

## 点击 Tabs 刷新

首页、搜索、我的主页：点击当前 Tab 或切换到其他 Tab 都刷新对应内容，从第一页／首屏开始，焦点保留在点击的 Tab。只移动遥控器焦点不请求数据；输入法未提交的搜索草稿不自动提交。视频筛选仍保留，旧查询／类型／账号的迟到响应不会覆盖新结果。

首页／视频搜索使用 CatalogViewModel 的 forceInitialRefresh 区分初始浏览与显式 Tabs 操作，后续同 Tab 刷新复用已有 refresh 命令。新类型搜索首请求和显式刷新均绕过旧 HTTP 缓存，个人列表和直播复用各自只读刷新路径。仅删除当前目标列表的 UI 位置记忆，不清全局缓存、账号数据或其他页面位置。

## 番剧详情

按用户参考图重排为顶部作品区、下方资料／分组选集区：

- 顶部为完整 3:4 大封面、封面色彩模糊背景、标题、标签、评分／人数、播放／追番／弹幕统计、开播及更新状态、简介和实际播放入口。
- 下方玻璃 Tabs 为“作品详情／选集／角色与制作”，支持点击刷新资料；正片／附加内容继续独立分组。
- 选集使用带真实缩略图的网格，每个范围至多两行，随屏宽调整列数；范围按钮切换，方向键可连续跨范围，不一次创建全部长选集卡片。
- 大屏资料页在选集右侧显示配音，小屏移到下方；可展开配音和制作人员。完整简介可单独打开阅读。
- 进入时聚焦播放入口；向下进入 Tabs／选集。播放返回恢复原剧集与范围，组内播放和自动下一集仍使用既有类型化路径与权限校验。

用户已明确本轮只改布局和选集，长评／短评延期，没有空壳剧评 Tab。未增加追番、分享、评分或其他账号写操作；图中的数值仅在接口真实返回时展示，缺失字段保持缺失。

## 数据与架构

保持 Flutter＋Riverpod＋Freezed＋MVVM／整洁架构。Data 扩展既有季详情映射：rating、stat、styles、publish、new_ep、actors、staff 和 episodes[].cover，Domain 使用可缺省 SeasonFacts 与剧集封面字段。无新数据库 schema、依赖或原生播放器变化。公共样本为季 281《甘城光辉游乐园》，与用户截图对应。

公共只读复验命令：`dart run tool/detail_layout_probe.dart`；报告见 [接口证据](detail-layout-evidence/interface-spike.json)。模糊范围限制在作品区，缩略背景按低分辨率解码；不引入循环动画或自定义折射着色器，不将这次界面改动表述为 M8 弹幕持续性能已通过。

## 验证

本轮新增 12 项回归，覆盖自动续载、去重、失败保留与重试、账号代次拒绝、Tabs 强制刷新、长简介遥控阅读、深浅主题／两种尺寸、顶部初始位置，以及 Android 返回不重复出栈。最终 **307／307** 测试通过、静态分析零问题、302 文件格式无变化，见 [结构化检查](detail-layout-evidence/validation.json)；本机日志在 `.m0/detail-redesign/`。

原生使用 API 36 x86_64 的 `Mamba_TV_API36`，隔离包 `app.mamba.mambatv.validation`、游客、只读。Flutter MCP 热重载成功，运行时错误为空；真实季 281 的海报、评分和资料可见，方向键从第 1 集跨两个范围到第 13 集，浅色选集范围和主 Tabs 切换可用；原生 Back 返回列表，不再重复触发退出框。视频详情向下滚动展示纵向四列网格并自动接入发现推荐，无需点击加载按钮。结束时关闭驱动输入模拟。
