## TV 播放实测

证据：[tv-playback.json](m0-evidence/tv-playback.json)。

- 视频：公开普通 UGC，H.264／AVC，640×360，独立视频与音轨。
- 首帧：最终配置单样本 530 ms，不是 P95 性能验收。
- 音轨：48 kHz、2 声道，Android 音频输出已提交帧；未进行人工听感判断。
- 暂停后位置稳定；seek 至 10 秒，恢复后记录位置 10.433 秒。
- 安全存储使用合成非秘密标记完成写入／读取／删除，未保存账号凭据。
- 播放器事件错误计数为 0。默认 gpu 输出在 SwiftShader 和 host GPU 模式都出现 EGL 黑屏，切换为 mediacodec_embed / mediacodec 后可见；虚拟解码器为 c2.goldfish.h264.decoder，不能宣称物理硬解通过。
- [最终可见画面](m0-evidence/tv-playback-embed.png) 与 [契约扩展验证](m0-evidence/extended-contracts.json) 作为独立证据，避免把首帧事件当作可视结果。
