# 卡片与导航调整

日期：2026-10-27。

「我的投稿、收藏夹、追番、追剧、稍后再看」复用首页 TvCapsuleTabs。共享圆角轨道与选中胶囊，方向键移动焦点、确认切换，向下进入内容；最左向左返回侧栏，最右向右进入刷新。选中栏目与当前焦点分别表达，保留各栏目列表及焦点记忆。

侧栏顺序调整为发现、历史记录、搜索、我的、设置，底部移除账号状态头像；「我的」页个人头像保留。路由分支索引不变，视觉和上下键顺序通过同一份映射驱动。底部主题按钮向上返回设置。

VideoSummary 新增可空 creatorAvatarUrl。推荐、热门、排行、相关视频读取 owner.face，搜索读取 upic，关注动态读取 module_author.face，历史读取 author_face，收藏夹视频和稍后再看读取 upper.face／owner.face。只使用响应已有字段；没有头像时保留圆形占位，不逐卡请求资料接口。我的投稿可复用已加载的本人资料头像。图片统一 HTTPS、已有缓存及 96 像素解码上限，加载失败回退占位。

TvVideoCard 将头像与作者名放在封面下方；个人视频复用此卡片，文件夹和剧集卡片以及历史列表也使用统一 LiquidGlassCard。整个圆角卡片包含透明渐变、边缘高光、阴影及局部背景模糊，遥控器聚焦时显示强调色玻璃边缘。网格使用 BackdropGroup 共享非重叠区域的模糊输入；没有逐卡持续动画或自定义折射着色器。减少动效设置继续关闭焦点缩放。

本地数据库升级至 v3，历史视频增加可空头像列。v1 直接创建最新元数据表；v2 仅增加可空列，保留账号隔离、观看位置、搜索记录和视频元数据。历史快照没有头像时显示占位，后续观看记录可写入真实头像。

本机完整回归 **240 项通过**，包括新侧栏上下键与主题返回路径、卡片整块确认行为、头像字段映射、v1/v2 到 v3 迁移及记录保留、深浅主题和 640×360／960×540 自适应布局。Flutter MCP 静态分析无诊断，239 个文件格式检查无变化。

API 36 x86_64 TV 模拟器使用隔离验证包检查了深浅首页、真实公共作者头像、玻璃卡片、历史入口及方向键返回侧栏。Flutter MCP 热重载成功，无运行时异常，结束后恢复深色首页。本轮模拟器为游客身份，个人主页胶囊通过合成账号组件测试验证；未重新进行真实账号扫码验收。物理电视和 ARM 未验收。
