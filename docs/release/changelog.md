# MambaTV 1.1.0（M8 本地候选，未发布）

- 新增普通视频 JSON 字幕：轨道／AI 标识、语言、字号、底部位置、±5 秒偏移与同分 P 切画质选择保留。
- 新增默认关闭的只读滚动／顶部／底部弹幕，以及文字透明度、区域、密度、本机关键词和自动负载降级。活动上限依次为 40／20／10 条，持续超载后暂停并提示；画布使用官方库的 Flutter ticker。
- 新增 UP 公开视频页、首页关注视频分页、搜索排序／时长筛选、全局观看增强设置；继续以遥控器焦点和 iOS 风格面板为主。
- 字幕／弹幕请求、解析与绘制按内容／账号代次隔离，seek／换 P／后台／关闭清理工作；JSON／protobuf 有响应和条数上限。
- 修复连续快进／快退重复排队及过早认定原生跳转完成：合并目标、显示等待位置、确认音画就绪后结束，超时按目标位置受限重载；暂停意图和账号隔离继续保留。验证见[跳转修复记录](../playback-seek-sync-fix.md)。
- 继续 Riverpod＋Freezed＋MVVM／整洁架构，Drift 保持 v2。新增 protobuf 生成与来源守卫；canvas 使用官方 Pub 包，先前本地补丁只留作历史试验记录。
- 本轮真实账号读取字幕正文、弹幕、UP、关注与筛选搜索通过，远端写入为 0。202 项 Flutter 回归、静态分析与 13 项流水线守卫本机通过；持续弹幕压力尚未通过，原生 profile 结果与限制见 M8 验收记录。

源版本为 1.1.0+2。先前 ARM32／ARM64 本机签名候选使用正式证书，但构建于切回官方画布之前，已与当前源码不一致且 `releaseQualified=false`。新 GitHub 标签、托管 CI 和公共 Release 尚未执行。点赞／投币独立延期，M9 未实施；物理 ARM TV、人工音画／字幕观感及真实写入仍待验收。M7 的历史时钟异常保留，不能用本轮自动结果抹去。

# MambaTV 1.0.0

首次发布，面向 Android TV／盒子，最低 Android 7.0（API 24）。提供 `arm64-v8a` 和 `armeabi-v7a` 两种 APK；`x86_64` 仅保留在 CI Debug artifacts。稳定性采样按用户要求为 15 分钟。

- 新增本地观看记录、远端历史、收藏夹及稍后再看，按账号隔离并支持显式管理。
- 支持遥控器焦点导航、iOS 风格界面、发现、搜索、视频详情、扫码登录与原生视频播放。
- 增加默认倍速、清晰度、分 P 连播、可选观看进度同步和保留持久记录的缓存清理。
- Drift v1 升级到 v2，保留已有进度与搜索；无元数据的旧视频仍显示可识别记录。
- 新增 TV 图标、品牌 banner 和支持遥控器浏览的开源许可页。
- 完善发布包文档、依赖／原生组件声明及 SHA256；精确检查 build number 与 ABI 对应的 versionCode。
- 个人列表写入结果不确定时只重新读取，不自动重复提交；真实账号本轮仍仅做只读验证。

已通过本机单元／组件测试、TV 模拟器 15 分钟播放和切页资源释放检查。物理 ARM 电视、人工音画同步、真实账号写入仍待验收；一次自动采样曾出现约 14.3 秒音画时钟差异常，详情见 known-limitations.md。正式发布使用长期保管的签名密钥；M7 的一次性测试证书不用于发行。实际签名、提交、版本和 ABI 以同批 build-metadata.json 为准。
