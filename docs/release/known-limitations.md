# 已知限制与验收范围

2026-10-25，M7 本轮按用户调整为 15 分钟稳定性采样，不以此宣称两小时通过。

- 主目标是 Android TV，最低 API 24；实际设备验证目前为 API 36 x86_64 模拟器，ARM 仅完成构建。尚无物理电视／盒子的兼容性结论。
- 已覆盖普通 UGC 的 AVC／AAC；HEVC、AV1、HDR、杜比和会员受限内容没有列为已支持。
- 真实账号历史、收藏夹、夹内视频、稍后再看只读已通过；真实收藏变更和进度心跳本轮仍未授权验收。
- 15 分钟 profile 采样曾出现单点原生 avsync 约 14.3 秒，下一分钟恢复；该记录不作为人工音画同步通过的结论。
- 人工听感／口型同步、物理遥控器中断、自然凭据续期／过期／风控仍待补充。
- 在线播放需要网络；本地记录可离线读取，不提供离线下载。
- v1.0.0 发布资产不含 M8／M9 新功能；后续工作区实现与验证范围见下文，不代表已发布。
- M7 构建与升级试验使用一次性测试证书。公开 Release 另用长期保管的正式证书；首版签名构建检查以同批元数据为准，正式证书的物理电视覆盖升级仍待验证。
- 原生媒体组件的许可证与来源已单列，正式分发前应复核成品二进制对应的源码、构建配方及原生组件材料，不能只使用 Dart 包装层的 MIT 声明。
- M6／M7 的历史验收文档记录当时的本机状态；公开发布须通过标签指向提交的完整托管 CI，旧提交的成功记录不能替代本轮结果。

当前采样是否通过及失败诊断以 [M7 验收](../m7-validation.md) 为准。


## M8 本地候选的范围

- 只支持已验证的 UGC JSON 字幕及普通滚动／顶部／底部弹幕；不提供 SRT／VTT 导入、翻译、高级／BAS 弹幕或弹幕发送。
- 字幕权限、可用轨道与 AI 标识以服务端返回为准；本轮真实样本是一轨 AI 字幕，多轨切换主要由合成测试覆盖。字幕偏移不校正原生音画问题。
- 弹幕库采用官方 canvas_danmaku 0.3.3；活动数量自动降为 20 条、最低 10 条，画布跟随 Flutter ticker，不保证单独的 30／15 fps 档位。负载持续超标时暂停弹幕，由用户手动重开；不自动反复升档。TV 模拟器的持续弹幕性能尚未通过。
- API 36 x86_64 模拟器在 host GPU、1920×1080／density 320 下未通过 M8 弹幕性能门槛。官方包仅弹幕、公开真实分段的最新 A/B 对照保持弹幕启用，但 raster P95=17.514 ms，超过 16.7 ms；此前较短保护窗口曾自动暂停。20 条／秒合成压力也曾自动暂停。不能推断 ARM 真机会通过。见 `docs/m8-evidence/danmaku-real-rejected-native.json`、`danmaku-rejected-native.json`；先前本地补丁的 `native-final-summary.json` 和 `rejected-final-retained-cap.json` 是历史对照。M8 候选仅供测试，尚不具备本计划规定的发布验收资格。
- UP 只列公开视频；关注只映射普通 archive 卡片，图文／直播／番剧过滤并提示。基础搜索只承诺排序及已映射时长选项；其他内容与投屏／下载／多账号属于 M9 之后的独立验证。
- 真账号只读验收 remoteWrites=0；没有新增点赞／投币命令。自然凭据续期、权限受限字幕、物理 ARM TV、人工音画／遥控器及正式设备覆盖升级仍待验收。
- 本轮源码、本机检查、模拟器结果和本地签名候选分别见 M8 记录；它们不等于新一轮托管 CI 或公共 Release。既有 v1.0.0 的资产和历史报告保持原样。

## M9 工作区范围（2026-10-28，未发布）

2026-10-29 增量：搜索已扩展视频／番剧／影视／直播切换，原有视频筛选保留，Tabs／侧栏统一玻璃，见 [搜索记录](../search-types-and-glass.md)。下列 2026-10-28 的“关键词搜索待补”属于历史范围；影视完整索引分类、直播推荐风控、物理／人工和正式发布限制继续保留。

- 已实现类型化内容、PGC 详情／选集／本地续播／下一集、HLS 基础直播及 Drift v4；验证分级见 [M9 验收](../m9-validation.md)。不升级这些记录为 v1.0.0 的发布能力。
- PGC 只播放当前权限下的完整 DASH；会员试看／不支持的 DRM 拒绝。游客免费样本已实测，真实会员权限及完整影视分类待补；2026-10-29 已接入番剧／影视关键词搜索。
- 直播推荐实测 -352，显示错误并提供房间号／链接直达；仅验证 HLS／TS／AVC。直播不提供点播 seek／倍速／续播／字幕弹幕；暂停后重新进入直播边缘。备源选择、真实断网／全部清晰度和物理电视待补。
- 无 PGC／直播远端心跳与互动，无聊天室、投屏、下载、多账号。原生回归、人工听感、正式签名升级和托管 CI 分别记录；M8 最高密度持续帧性能缺口继续保留。
